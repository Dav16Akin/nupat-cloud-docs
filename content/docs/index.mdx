# Welcome to Nupat Cloud Documentation

Nupat Cloud is an enterprise-grade cloud infrastructure and hosting platform designed specifically for African businesses, agencies, developers, and startups.

## Quick Navigation

Explore our key documentation sections:

- **[Getting Started](/docs/getting-started/creating-account)**: Create your account, verify your email, and tour the client dashboard.
- **[Web Hosting & cPanel](/docs/hosting/cpanel-access)**: Access your cPanel, install WordPress in 1-click, configure MySQL databases, and set up business emails.
- **[Domains & DNS](/docs/domains/registering-domains)**: Search and register `.com`, `.ng`, `.africa` domains, update custom nameservers, or transfer existing domains.
- **[SSL & Security](/docs/ssl/automated-ssl)**: Understand automated 256-bit Let's Encrypt certificates, HTTPS redirects, and DDoS mitigation.
- **[Billing & Invoices](/docs/billing/payment-methods)**: Learn about Paystack payments in NGN, downloading WHMCS invoices, and auto-renewals.
