# What is an Auth / EPP Code?

An **Auth Code** (also called an **EPP Code**, **Transfer Key**, or **Auth-Info Code**) is a unique secret passphrase generated by the domain registry to authenticate domain ownership.

## Why is it Required?

The code acts as a security lock to prevent unauthorized domain transfers and domain hijacking.

## Finding Your Nupat Cloud Auth Code

If you wish to transfer a domain registered on Nupat Cloud to another provider:
1. Log in to your [Dashboard](https://nupatcloud.com/dashboard/domains).
2. Select your domain.
3. Click **Get EPP Code**.
4. Your Auth Code will be displayed and emailed to your registered address.
