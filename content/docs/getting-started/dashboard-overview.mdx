# Client Dashboard Overview

Once signed in, your **Client Area** serves as your central command hub for all active hosting services, registered domains, invoices, and support tickets.

## Key Sections

- **Hosting Accounts**: View active cPanel packages, storage utilization, bandwidth metrics, and one-click cPanel login.
- **My Domains**: Manage DNS records, name servers, auto-renewals, and auth transfer codes.
- **SSL Certificates**: Monitor active 256-bit certificates and trigger instant re-issuance.
- **Orders & Invoices**: Access payment history, Paystack reference IDs, and downloadable WHMCS PDF receipts.
- **Support Tickets**: Open direct high-priority inquiry tickets with our engineering team.
