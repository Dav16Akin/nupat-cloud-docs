# Nupat Cloud CLI

The `@nupat/cloud-cli` lets developers deploy and inspect cloud environments directly from their terminal.

## Installation

```bash
npm install -g @nupat/cloud-cli
```

## Authentication

```bash
nupat login
```

## Deploying an App

```bash
nupat deploy --env production --region lagos-01
```

## Checking Server Telemetry

```bash
nupat status
```
