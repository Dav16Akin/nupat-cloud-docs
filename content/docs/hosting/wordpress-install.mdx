# Installing WordPress in 1-Click

Nupat Cloud includes the **Softaculous 1-Click Application Installer** inside cPanel to deploy WordPress in seconds.

## Installation Steps

1. Log in to your **cPanel**.
2. Scroll to the **Software** section and click **WordPress Manager by Softaculous**.
3. Click **Install**.
4. Configure your setup:
   - **Protocol**: Select `https://` (SSL is pre-configured).
   - **Domain**: Choose your domain name.
   - **Directory**: Leave blank to install on your root domain.
   - **Admin Account**: Set your admin username, password, and email.
5. Click **Install** at the bottom of the page.
6. Once completed, your WordPress site and admin dashboard (`/wp-admin`) are immediately live.
