# Managing MySQL Databases

All Nupat Cloud hosting tiers run high-performance MySQL/MariaDB database servers.

## Creating a Database via cPanel

1. In cPanel, click **MySQL Databases** or **MySQL Database Wizard**.
2. Enter a database name (e.g. `user_production`) and click **Next Step**.
3. Create a database user and generate a secure password.
4. Check **All Privileges** and click **Make Changes**.

## Accessing phpMyAdmin

- In cPanel, go to **Databases** > **phpMyAdmin**.
- You can import `.sql` dumps, execute custom queries, and inspect tables.
