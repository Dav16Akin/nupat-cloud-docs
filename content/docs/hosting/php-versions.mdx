# Managing PHP Versions & Extensions

Nupat Cloud supports multiple PHP versions with instant toggling.

## Changing PHP Version

1. In cPanel, go to **Software** > **MultiPHP Manager**.
2. Select your domain from the list.
3. In the **PHP Version** dropdown, choose `ea-php81`, `ea-php82`, or `ea-php83`.
4. Click **Apply**.

## Enabling PHP Extensions (Redis, Imagick, etc.)

1. In cPanel, go to **Select PHP Version** (or **MultiPHP INI Editor**).
2. Check or uncheck required extensions (`redis`, `imagick`, `curl`, `mbstring`, `zip`, `intl`).
3. Click **Save**.
